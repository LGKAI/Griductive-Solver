# Griductive Solver (CSC14003 Project 2)

A no-guess Griductive deduction game with a logic agent: automatic CNF encoding, a DPLL SAT
solver written from scratch, entailment checks (KB ∧ ¬C unsat ⇒ forced), and a web GUI.

| Folder / file | Contents |
|---|---|
| `Source/` | Python source (standard library only): `griductive/` package, web GUI, tests, experiments. See [Source/README.md](Source/README.md). |
| `report_latex/` | LaTeX source of the report (`main.tex`, compile with XeLaTeX). Data-driven parts are generated by `python3 report_latex/gen_data.py`. |
| `Report.pdf` | Compiled report (Vietnamese). |
| `Video_Script.md` | Script for the demo video. |

Quick start:

```bash
cd Source
python3 main.py                              # GUI at http://127.0.0.1:8765
python3 -m unittest discover -s tests -v     # test suite
python3 experiments.py                       # experiments -> Source/results/
```
